Already good (kept as is)

Strengths

  • Visible labels above every field, no placeholder-only inputs
  • Correct autocomplete and input types on email, name, organization
  • Reduced-motion rules in CSS, and autoplay off when it is set
  • Good colour contrast on body text and buttons
  • Responsive layout with container queries, no horizontal scroll

Not changed — your call

  • Admin pages: not touched. The admin photo viewer uses the same pattern, so it would benefit from the same focus fix.
  • Survey iframe has a fixed 1500px height, so long forms scroll inside the page. Microsoft Forms controls this.
  • Consider a sticky “Get 2027 updates” button on phones, since the mailing list is the main goal.
  • Google Fonts loads 8 weights; trimming to the ones used would speed first paint.

How to adopt

  • The improved code lives in assets/site.improved.css and assets/site.improved.js.
  • To go live, point your pages at those files, or rename them over site.css / site.js. No page HTML needs to change.
  • Test once with the real Firebase connection, since previews run in demo mode.
